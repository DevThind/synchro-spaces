# CMS editor guide

## Content types

Studio provides site settings, services, projects/case studies, technology partners, articles/resources, FAQs, service areas, team members, testimonials, and campaign pages. Shared image, CTA, video, SEO, and Portable Text objects keep entry consistent.

## Publishing workflow

1. Draft content with a clear audience and concise summary.
2. Add images only when usage rights are documented; every image requires purposeful alternative text.
3. Complete SEO title/description and review the generated route in Presentation preview.
4. Confirm related services, projects, and locations create useful internal links.
5. Verify facts, brand relationships, credentials, dates, and claims with the accountable client reviewer.
6. Set editorial status to Published and publish the Sanity document.
7. Set and honour the next review date.

Testimonials cannot pass validation without recorded written publication approval. Technology-partner relationships remain explicitly unverified until confirmed. Service-area entries require real local insights and must never become near-duplicate doorway pages.

Do not enter secrets, customer credentials, alarm/door codes, private network details, or sensitive security layouts in Studio.
